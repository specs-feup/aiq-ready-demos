# SIMD Transform 

- Install Java 17+ (21 recommended)
- Install Node v20 or v22 (v22.16.0 recommended)
- Clone the workspace repo (https://github.com/specs-feup/clava-simd-transform-workspace)
- cd into the workspace repo and run `npm run initialize`
- cd into the nvision-simd-clava-pass directory and follow the Quickstart section of the README
